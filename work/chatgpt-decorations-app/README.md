# ChatGPT 装饰版 App 3.2.5

3.2.5 修复新版客户端中“装饰配置”入口回退到“宠物”下方的问题：兼容“已归档的聊天”新名称，并在名称变化时自动选择侧栏最靠下的菜单项。继续保留预览署名、来源标记、GIF 动画、换图无闪烁和更新重启自动接管。

## 日常启动

1. 把 `ChatGPT 装饰版.app` 拖到“应用程序”文件夹，或直接放进 Dock。
2. 先用 `Cmd+Q` 完全退出官方 ChatGPT。
3. 双击或从 Dock 点击 `ChatGPT 装饰版`。

首次成功启动会自动在 `~/Applications/ChatGPT 装饰版.app` 安装稳定副本。建议把这个固定路径中的 App 放进 Dock；以后官方更新完成并重启原版时，用户级接管器会自动切换回装饰版。

首次启动会在以下目录创建可编辑配置：

`~/Library/Application Support/ChatGPTDecorations/`

以后更新 App 不会覆盖这个目录中的 `decorations.json` 和图片。

## 新增或修改装饰

推荐直接打开 Codex 的设置，在侧栏底部选择“装饰配置”。设置页会实时预览，点击“保存设置”后立即应用并写入用户配置。

如需手动编辑原始 JSON，仍可双击 `编辑装饰配置.app`。它会：

- 在 Finder 中打开配置目录；
- 用 TextEdit 打开 `decorations.json`；
- 保留 `assets/` 中的图片。

保存后完全退出 ChatGPT，再打开 `ChatGPT 装饰版.app` 即可重新载入。

## 恢复原版

双击 `恢复原版 ChatGPT.app`。它会先关闭更新重启自动接管，再停止注入器、退出主题模式并正常启动官方应用，不会删除账号、会话或装饰配置。以后再次打开装饰版会重新启用接管。

## 更新重启接管

接管器只检查 ChatGPT 主进程是否带有装饰版所需的本机调试参数：

- 正常的装饰版进程不会被打断；
- 官方更新后直接启动的普通进程会在短暂初始化后退出，并从固定路径启动装饰版；
- 所有调试连接仅使用 `127.0.0.1`；
- 使用“恢复原版”即可完整关闭接管器。

## macOS 首次打开提示

本 App 使用本地临时签名，没有 Apple 公证。如果 macOS 阻止首次打开，请在 Finder 中右键 App，选择“打开”，再确认一次。

官方 ChatGPT.app 始终保持原签名和原始文件，未被修改。

## 构建与旧版本清理

开发目录中双击或运行 `build-release.command` 会先构建、签名、自检并解压复验当前版本。只有全部验证成功后，它才会清理 `outputs` 中的旧装饰包，并只保留最新版本目录及 ZIP。用户配置目录不会被清理。
